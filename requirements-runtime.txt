# Runtime dependencies for the LIVE TRADING path only (Modal image).
#
# Determined by importing scripts/run_trading.py's dependency graph and recording
# what third-party modules actually load - not by guessing. The full
# requirements.txt is ~20 packages; the trading path touches five, and pulling in
# selenium/streamlit/matplotlib/scikit-learn/yfinance would triple the image build
# for code that never executes there.
#
# Notably absent and deliberately so:
#   selenium, webdriver-manager  - scrapers, which run in GitHub Actions
#   streamlit, matplotlib, seaborn - the dashboard
#   scikit-learn, scipy          - backtest/analysis
#   openai                       - the LLM classifier, runs in the nightly job
#   polygon-api-client           - never adopted; Polygon was out of scope
#
# schwab-py and yfinance are imported LAZILY (inside functions), so they do not
# appear in an import trace of the module graph - both are required at runtime.
# yfinance in particular: signals/generate.py::_price_snapshot uses it for the
# current price that drives sizing and the price floor. Without it every signal
# comes back priceless and every entry is silently skipped.
