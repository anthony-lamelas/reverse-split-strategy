# Runtime dependencies for the LIVE TRADING path only (Modal image).
#
# Determined by importing scripts/run_trading.py's dependency graph and recording
# what third-party modules actually load - not by guessing. The full
# requirements.txt is ~20 packages; the trading path touches five, and pulling in
# selenium/streamlit/matplotlib/scikit-learn/yfinance would triple the image build
# for code that never executes there.
#
# Notably absent and deliberately so:
#   selenium, webdriver-manager  - scrapers, which run in GitHub Actions
#   streamlit, matplotlib, seaborn - the dashboard
#   scikit-learn, scipy          - backtest/analysis
#   openai                       - the LLM classifier, runs in the nightly job
#   polygon-api-client           - never adopted; Polygon was out of scope
#
# schwab-py is imported LAZILY (inside functions), so it does not appear in an import
# trace of the module graph - it is required at runtime.
#
# yfinance is NO LONGER used for sizing. `_price_snapshot` is gone: prices now come
# from Schwab quotes via generate_signals(quote_fn=...), because yfinance returns an
# empty frame rather than an error for a throttled or unrecognised symbol, and those
# names were skipped as "missing or invalid price" - a third of all skips over the
# first fortnight live, including two candidates above the $1.00 floor.
#
# It is kept here deliberately, for now. An import trace confirms the live path no
# longer loads it, but this same comment block exists because a lazy in-function
# import does not show up in such a trace, and this file builds the image that trades
# real money at 09:25. The cost of keeping an unused wheel is a slightly larger image;
# the cost of being wrong is a halted trading day. Drop it after a few clean live runs.
